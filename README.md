 🛍️ E-Commerce Sales Performance Analyzer Using Python

📌 Project Overview
The E-Commerce Sales Performance Analyzer** is a Python-based data analytics project that analyzes fashion e-commerce sales data from 2022 to 2025.

The project uses Python libraries to clean, transform, analyze, and visualize data to identify sales trends, customer purchasing behavior, product performance, and profitability.

🎯 Project Objectives
- Analyze overall sales and profit performance.
- Identify top-selling products and brands.
- Understand customer purchasing behavior.
- Analyze monthly and yearly sales trends.
- Compare category-wise and city-wise sales.
- Evaluate the impact of discounts on profitability.
- Generate meaningful business insights through visualizations.

🛠️ Technologies & Libraries Used
- Python– Programming language
- Pandas – Data cleaning and manipulation
- NumPy – Numerical operations and data analysis
- Matplotlib – Data visualization
- Seaborn – Statistical data visualization
- Plotly – Interactive charts
- Google Colab – Development environment

 📂 Dataset Description
The project uses three CSV files:

| File Name | Description |
|---|---|
| orders.csv | Order details, sales, quantity, profit, payment mode and order status |
| products.csv | Product details, category, brand, price and cost price |
| customers.csv | Customer details, age, gender, city, state and customer segment |

Data Period: 2022–2025

🧹 Data Cleaning & Processing
- Loaded multiple CSV files using Pandas.
- Checked missing values and duplicate records.
- Converted order dates into datetime format.
- Extracted year, month and quarter from order dates.
- Merged orders, products and customers datasets.
- Filtered delivered orders for sales and profit analysis.
- Created additional categories using NumPy.

💡 Business Insights
The analysis helps understand:
- Which product categories generate the highest revenue.
- Which brands and products perform best.
- How sales change across months and years.
- Which cities contribute more to revenue.
- How discounts affect profitability.
- How frequently customers make repeat purchases.
